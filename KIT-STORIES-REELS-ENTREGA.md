# Entregável — 8 briefs Stories/Reels + roteiro 15s

## Briefs (cole no Studio / chat web)
1. **Gancho dor:** «Escreve 3 ganchos de Stories (máx 12 palavras) pra [nicho] que sente [dor]. Tom direto, sem emoji excessivo.»
2. **Prova social:** «Transforma este depoimento em 1 frame de Stories + CTA fraco→forte: [depoimento].»
3. **Oferta relâmpago:** «Roteiro Stories 4 frames: problema / agitação / oferta R$[x] / PIX CTA. Produto: [x].»
4. **Reels 15s:** «Roteiro falado 15s (início 3s gancho) pra [produto]. Sem jargão.»
5. **WhatsApp Status:** «3 legendas Status (1 linha) + 1 pergunta que gera reply, pra [serviço].»
6. **Objecção preço:** «Resposta em Stories (2 frames) à objecção “tá caro” sem desconto mentiroso.»
7. **Bastidores:** «Prompt pra copy de bastidores autênticos (processo, não flex) de [ofício].»
8. **CTA soft:** «3 CTAs soft (“salva / responde COM X / link na bio”) alinhados a [oferta].»

## Template roteiro 15s
- 0–3s: gancho visual + frase  
- 3–10s: prova / demo  
- 10–15s: CTA + onde pagar/falar  

## Checklist humano
- [ ] Claim verificável  
- [ ] Preço/PIX corretos  
- [ ] Sem cold-DM spam
